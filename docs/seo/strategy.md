# SEO Strategy

SEO is part of the product development process, not a later marketing task.

## Initial search problem

The primary opportunity is the gap between AI-generated frontend code and a conventional runnable project.

## Initial intent clusters

### Troubleshooting

These are research seeds, not validated keyword decisions.

## SEO rule

Do not publish pages solely because a keyword exists.

Each page should satisfy a real search intent and provide useful information or functionality.

## Measurement loop

Hypothesis → Publish/implement → Index → Measure → Evaluate → Update

Track:

- impressions
- clicks
- CTR
- ranking
- organic users
- tool opens
- conversions
- successful builds
- failed builds

The resulting evidence should feed future SEO decisions.
